# Flappy AI 

A evolutionary algorithm that trains an AI to play Flappy Bird using an **Evolutionary Algorithm**. Built with the Godot Engine and C#. 

## Features

* **Evolutionary Algorithm:** Custom implementation to evaluate fitness, select the best performers, and apply mutations to breed the next generation of agents.
* **Godot Engine Integration:** Built entirely in Godot with a C# backend for robust performance and object-oriented architecture.
* **Real-time Training:** Watch the AI learn in real-time as each generation progressively gets better at the game.

## Technologies Used

* **Game Engine:** [Godot Engine](https://godotengine.org/) (.NET version)
* **Language:** C#
* **AI Concept:** Evolutionary Algorithms / Neural Networks
